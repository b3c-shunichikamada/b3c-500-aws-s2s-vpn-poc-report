01 / OVERVIEW

検証概要

本PoCでは、AWS東京リージョン（ap-northeast-1）に2つの独立したVPCを構成し、SITE-A側のYamaha Virtual Router vRXとSITE-B側のAWS Virtual Private Gateway（VGW）間にIKEv2/IPsecトンネルを確立した。双方のEC2インスタンスによる通信試験と、トンネル・暗号化セッション・ルーティングの状態確認を実施した。
